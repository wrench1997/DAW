# FIT NOTES phrase framing — 2026-10-17

## Change

`src/app/editor_navigation.rs` now fits the selected channel's earliest note start through its latest note end, rather than always fitting from beat zero. A phrase at beats 128–132 therefore gets the same useful horizontal scale as a four-beat phrase at the beginning of a pattern.

- Retains the existing 12-pixel horizontal margin and pitch-fitting behavior.
- Empty patterns and empty selected channels retain the first-bar (0–4 beats) fallback without changing pitch navigation.
- Other channels and unassigned ghost notes do not expand a selected channel's fitted range. The existing unassigned-target matching behavior is unchanged.
- Existing viewport scale/content constraints remain authoritative. Extremely long phrases that cannot fit at the minimum scale reveal their leading edge; boundary padding is clamped at content edges.
- Only the viewport is mutable input to the extracted fitting helper. Project content, note selection, playback state, and Undo history are not changed.

## Regression coverage

Nine module tests cover late phrases and repeated fitting, empty patterns, single short notes, long-note tails, minimum/maximum zoom constraints, ghost-channel isolation, empty selected channels, unassigned targets, and time/pitch boundaries.
